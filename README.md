# gestion-emplois-du-temps
Application web de gestion des emplois du temps universitaires développée avec Angular, Laravel et Bootstrap, permettant aux étudiants et enseignants de consulter leurs cours et à l'administrateur de gérer les emplois du temps.
n web de gestion et de consultation des emplois du temps universitaires, développée dans le cadre d'un projet académique.

## Présentation

Cette application permet de centraliser la gestion des emplois du temps et de faciliter l'accès aux informations pour les étudiants, les enseignants et les administrateurs.

## Espace Étudiant

Les étudiants peuvent :

* Consulter les cours programmés
* Consulter leur emploi du temps
* Consulter les informations relatives aux enseignants
* Accéder aux informations nécessaires concernant leurs cours

## Espace Enseignant

Les enseignants peuvent :

* Consulter leur emploi du temps
* Voir uniquement les cours auxquels ils sont affectés
* Consulter les informations relatives à leurs enseignements

## Espace Administrateur

L'administrateur dispose d'un espace de gestion permettant de :

* Ajouter des emplois du temps
* Modifier les emplois du temps
* Supprimer des emplois du temps
* Gérer les cours et les affectations
* Administrer les informations nécessaires au fonctionnement de l'application

## 🏗️ Architecture

Le projet est organisé en deux parties :

```text
gestion-emplois-du-temps/
│
├── frontend/
│   └── Angular
│
└── backend/
    └── Laravel API
```

Angular assure l'interface utilisateur et communique avec l'API développée avec Laravel.

## 🎯 Objectif du projet

L'objectif est de proposer une solution permettant de simplifier la consultation et l'administration des emplois du temps universitaires tout en proposant des fonctionnalités adaptées aux différents profils d'utilisateurs.
